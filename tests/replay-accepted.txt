# Differences tests/replay_guard.py found that someone looked at and the guard means, such as a
# rule tightened on purpose. The replay leaves these out before it decides its exit code, so it
# fails only on a new difference.
#
# One per line:  <fingerprint> <half> <then>-><now>  # <why it's accepted>
#
# The fingerprint is the first 16 hex characters of the SHA-256 of the recorded command, or for a
# read, of json.dumps([tool, input, cwd], sort_keys=True). Never the command itself: it comes from
# the user's private transcripts, and this repo is public. The half is `base` (blocked at --base,
# allowed now), `read` (a recorded Read, Grep or Glob call refused now) or `headless` (a headless
# run's command, judged differently now from then). The replay prints each difference it finds
# with its first three fields, ready to copy here.
#
# An entry that no longer occurs is reported as stale but doesn't fail the run, since old
# transcripts age out. Delete it then.
